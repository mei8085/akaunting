```php
public function hasRow($row)
{
    // 1. 首次调用时预加载所有现有记录的指定字段
    if (! $this->has_row || ! $this->has_row instanceof $this->model) {
        $this->has_row = $this->model::withoutEvents(function () {
            return $this->model::get($this->columns)->each(function ($data) {
                $data->setAppends([]);
                $data->unsetRelations();
            });
        });
    }

    // 2. 基于配置的字段进行匹配检查
    foreach ($this->columns as $key) {
        $search_value[$key] = isset($row[$key]) ? $row[$key] : null;
    }

    // 3. 如果记录已存在则返回true（跳过导入）
    return in_array($search_value, $this->has_row->toArray());
}
```

### 3.2 账单匹配逻辑

**核心类**: `app/Jobs/Banking/MatchBankingDocumentTransaction.php`

#### 3.2.1 金额校验 (`checkAmount()`)

```php
protected function checkAmount(): bool
{
    // 1. 精度处理
    $transaction_precision = currency($code)->getPrecision();
    $document_precision = currency($this->model->currency_code)->getPrecision();
    
    // 2. 币种转换（如需要）
    if ($this->model->currency_code != $code) {
        $converted_amount = $this->convertBetween($amount, $code, $rate, 
            $this->model->currency_code, $this->model->currency_rate);
        $amount = round($converted_amount, $document_precision);
    }
    
    // 3. 计算未付金额
    $total_amount = round($this->model->amount - $this->model->paid_amount, $document_precision);
    
    // 4. 比较金额
    $compare = bccomp($amount, $total_amount, $document_precision);
    
    if ($compare === 1) {
        // 超额匹配：交易金额 > 未付金额，抛出异常
        throw new \Exception(trans('messages.error.over_match', [...]));
    } else {
        // 完全匹配或部分匹配
        $this->model->status = ($compare === 0) ? 'paid' : 'partial';
    }
    
    return true;
}
```

#### 3.2.2 匹配状态定义

| 状态 | 条件 | 说明 |
|------|------|------|
| `paid` | 交易金额 == 账单未付金额 | 账单完全付清 |
| `partial` | 交易金额 < 账单未付金额 | 账单部分支付 |
| 异常 | 交易金额 > 账单未付金额 | 超额匹配，禁止操作 |

### 3.3 拆分交易匹配

**核心类**: `app/Jobs/Banking/SplitTransaction.php`

#### 流程:
1. **金额校验**: 所有子项金额之和必须等于原交易金额 (`checkAmount()`)
2. **复制交易**: 为每个子项复制原交易，设置 `split_id` 关联
3. **分别匹配**: 每个子交易独立匹配对应账单
4. **更新类型**: 原交易类型标记为 `*-split` (如 `income-split`)

```php
public function handle(): array
{
    DB::transaction(function () {
        foreach ($this->request->items as $item) {
            $transaction = $this->model->duplicate();
            $transaction->split_id = $this->model->id;
            $transaction->amount = $item['amount'];
            $transaction->save();
            
            $document = Document::find($item['document_id']);
            $this->dispatch(new MatchBankingDocumentTransaction($document, $transaction));
        }
        
        $this->model->type = config('type.transaction.' . $this->model->type . '.split_type');
        $this->model->save();
    });
}
```

```php
public function handle(): Reconciliation
{
    \DB::transaction(function () {
        // 1. 创建对账记录
        $this->model = Reconciliation::create($this->request->all());
        
        // 2. 批量更新交易对账状态
```

### 4.2 更新对账

**核心类**: `app/Jobs/Banking/UpdateReconciliation.php`

```php
public function handle(): Reconciliation
{
    \DB::transaction(function () {
        $reconcile = (int) $this->request->get('reconcile');
        $transactions = $this->request->get('transactions');
        
        $this->model->transactions = $transactions;
        $this->model->reconciled = $reconcile;
        $this->model->save();
        
        if ($transactions) {
            foreach ($transactions as $key => $value) {
                $transaction_reconcile = $reconcile;
                
                // 未选中的交易取消对账
                if (empty($value) || $value === 'false') {
                    $transaction_reconcile = 0;
                }
                
                $t = explode('_', $key);
                $transaction = Transaction::find($t[1]);
                $transaction->reconciled = $transaction_reconcile;
                $transaction->save();
            }
        }
    });
}
```

### 4.3 删除对账（撤销对账）

**核心类**: `app/Jobs/Banking/DeleteReconciliation.php`

```php
public function handle(): bool
{
    \DB::transaction(function () {
        // 1. 删除对账记录
        $this->model->delete();
        
        // 2. 批量回滚交易对账状态
        Transaction::where('account_id', $this->model->account_id)
            ->isReconciled()
            ->whereBetween('paid_at', [$this->model->started_at, $this->model->ended_at])
            ->each(function ($transaction) {
                $transaction->reconciled = 0;
                $transaction->save();
            });
    });
}
```

**关键点**: 撤销对账时，会将该对账时间范围内所有已对账的交易全部标记为未对账。

## 5. 边界处理分析

### 5.1 部分匹配场景

**场景**: 账单金额 $1000，银行到账 $300

**处理流程**:
1. 调用 `MatchBankingDocumentTransaction`
2. `checkAmount()` 计算: $300 < $1000 → `$compare = -1`
3. 账单状态设置为 `partial`
4. 交易关联到账单 (`document_id` 设置)
5. 后续可继续匹配剩余 $700

## 7. 总结

### 7.1 核心流程

```
导入Excel → 去重检查(按number) → 数据映射 → 关联解析 → 创建交易
                                                         ↓
手动/自动匹配 ← 交易列表 ← 未对账交易查询 ← 对账创建向导
       ↓
匹配账单 → 金额校验 → 完全/部分支付 → 更新账单状态
       ↓
对账 → 勾选交易 → 计算差额 → 确认对账 → 批量标记reconciled=1
       ↓
撤销对账 → 删除对账记录 → 批量回滚reconciled=0
```

### 7.2 设计亮点

1. **灵活的去重机制**: 基于可配置字段的预加载比对，性能优秀
2. **智能关联解析**: 支持按多种方式查找关联，缺失时自动创建
3. **精确的金额比较**: 使用 `bccomp` 进行高精度比较，避免浮点误差
4. **完整的状态机**: 账单支持 paid/partial 状态，交易支持 reconciled 状态
5. **拆分交易支持**: 一笔银行交易可拆分匹配多笔账单

### 7.3 注意事项

1. **撤销对账的广谱性**: 删除对账会影响时间范围内所有已对账交易，操作需谨慎
2. **交易编号唯一性**: 去重仅依赖 `number` 字段，导入数据需保证编号唯一
3. **已对账交易锁定**: 已对账/已关联账单的交易无法编辑或删除
4. **超额匹配保护**: 防止交易金额超过账单未付金额
